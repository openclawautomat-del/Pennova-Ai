=== Pennova AI – SEO Autoblogger ===
Requires at least: 5.8
Requires PHP: 7.4
Stable tag: 3.2.0
License: GPLv2 or later

Write SEO-optimised articles with any AI provider, add images and YouTube videos automatically, publish on autopilot, and get Telegram / WhatsApp alerts.

== Features ==
* 16 AI provider presets (OpenAI, Claude, Gemini, OpenRouter, Groq, DeepSeek, Mistral, xAI, Together, Perplexity, Fireworks, Cerebras, Cohere, Ollama, LM Studio) + any custom endpoint
* SEO: meta title/description (Yoast, Rank Math, AIOSEO), TOC, key takeaways, FAQ + schema, internal links
* Images: Unsplash, Pexels or AI-generated, fully responsive
* YouTube: relevant videos embedded automatically (click-to-play, lazy, responsive)
* Bulk generation, auto-pilot queue, scheduling
* Telegram + WhatsApp Agent alerts
* Encrypted API key storage

== Upgrade note ==
Deactivate and delete the old "AI Auto Poster" plugin first. Settings are kept (same option names).

== External services ==
This plugin connects only to services you configure. Data sent: article keywords/prompts (AI providers), search queries (image/video services), post titles and links (alerts).
* AI providers (OpenAI, Anthropic, Google, OpenRouter, Groq, DeepSeek, Mistral, xAI, Together, Perplexity, Fireworks, Cerebras, Cohere, or your own endpoint) – terms: see each provider's website, e.g. https://openai.com/policies/terms-of-use , https://www.anthropic.com/legal
* Unsplash API – https://unsplash.com/terms
* Pexels API – https://www.pexels.com/terms-of-service/
* YouTube Data API / embedded player – https://developers.google.com/youtube/terms/api-services-terms-of-service
* Telegram Bot API – https://telegram.org/privacy
* WhatsApp Agent API (Meta) – https://www.whatsapp.com/legal/
* You.com APIs (search, research, contents) – https://you.com/terms
